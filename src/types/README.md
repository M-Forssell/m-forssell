# Types

TypeScript type definitions.

- `componentTypes.ts` — UI variant enums (CardVariant, HeadingLevel, IconName, etc.)
- `storyblok.ts` — Storyblok data structures (blok interfaces, API response types)
- `storyblok-react-rsc.d.ts` — Type declarations for Storyblok React Server Components
- `svg.d.ts` — SVG module declarations
