# Components

Reusable UI components prefixed with `mf` (e.g., `mfCard.tsx`, `mfHeader.tsx`).

These have no Storyblok/CMS knowledge — they receive standard React props and can be used independently. Each component lives in its own folder with co-located styles and tests.

See [ARCHITECTURE.md](../../ARCHITECTURE.md) for the full bloks vs components distinction.
